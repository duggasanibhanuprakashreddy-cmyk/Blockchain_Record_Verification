⚡ How BlockVerify Works

📄 Record

Enter the digital record details such as ID, name, course, and CGPA.

🔐 Hash

Generate a unique, deterministic SHA-256 cryptographic fingerprint.

⛓️ Blockchain

Store the fingerprint inside a cryptographically linked, immutable block.

🛡️ Verify

Compare regenerated hashes to instantly detect unauthorized tampering.

🎯 Security Principle

✅ Same record → Same hash → VERIFIED
❌ Modified record → Different hash → TAMPERED
